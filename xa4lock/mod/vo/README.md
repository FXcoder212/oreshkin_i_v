# Озвучка Xa4lock (пилот: Бебопян)

- `bebop_pilot.json` — 44 реплики Бебопа на русском с армянским говором,
  путь к звуку игры для каждой реплики и голос ElevenLabs.
- `generate.py` — создаёт WAV-файлы через ElevenLabs у вас на компьютере
  (бесплатный тариф ElevenLabs не работает из облака/через VPN).

Запуск (Windows, cmd):

    set ELEVENLABS_API_KEY=ваш_ключ
    python generate.py bebop_pilot.json

Результат — папка `out/sounds/vo/bebop/...wav`. Дальше файлы нужно
скомпилировать в формат игры (.vsnd_c) и положить в аддон.

## Без ключа: Silero (бесплатно, локально)

    pip install torch numpy
    python generate_silero.py bebop_pilot.json aidar

Обычный русский диктор без говора (голоса aidar, eugene, baya, kseniya, xenia).
Лицензия моделей Silero — некоммерческая, для бесплатного мода подходит.

## С говором: клон голоса XTTS-v2 (бесплатно, локально)

    pip install coqui-tts
    python generate_xtts.py bebop_pilot.json образец.wav

образец.wav — 20–60 секунд речи человека, который согласен, что его голос
прозвучит в моде (голос и говор переносятся на все реплики). Лицензия XTTS-v2 —
некоммерческая. Очень короткие фразы модель иногда тянет: такие реплики
стоит сгенерировать ещё раз (можно передать их ключи после пути к образцу).
Записи-образцы в репозиторий не кладём.
