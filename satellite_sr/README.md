# Супер-разрешение ×4 спутниковых снимков

`sr_solution.ipynb` — готовый ноутбук для Google Colab (GPU), `sr_solution.py` — тот же код
в виде скрипта (ноутбук собирается из него: `jupytext --to ipynb sr_solution.py`).

## Запуск в Colab

1. Загрузите `sr_solution.ipynb` в Colab, «Среда выполнения → Сменить среду → T4 GPU» (или L4/A100).
2. «Выполнить всё». Ноутбук сам:
   * скачает данные напрямую с Kaggle (публичный датасет, ≈ 4.4 ГБ, ключ и Google Диск не нужны);
   * обучит модель, подберёт настройки на валидации, соберёт и проверит `submission.parquet`;
   * в конце предложит браузеру скачать `submission.parquet`.
3. По желанию `USE_DRIVE = True` в первой ячейке: чекпойнты и посылка пишутся в
   `MyDrive/sr_work`, и после отключения Colab «Выполнить всё» продолжит обучение с последнего
   чекпойнта (`train_state.pt`, каждые 1000 шагов). Без Диска всё лежит в `/content/sr_work`
   и пропадает при отключении сеанса.
4. Там же — бюджет времени: `SR_TIME_LIMIT_MIN`, `SR_STEPS_L1`, `SR_STEPS_METRIC`, `SR_EVAL_EVERY`.

## Что внутри

* **Модель**: RCAN-подобная сеть (6 групп × 6 блоков с канальным вниманием, 96 каналов, ≈ 7.3 M
  параметров), выход = бикубик + поправка сети; последний слой обнулён, старт ровно с бикубика.
* **Обучение**: 70k шагов L1 (патчи 48→192), затем 30k шагов на дифференцируемой копии метрики
  платформы (SSIM + MAE + лапласиан + Собель + HF, с теми же ядрами, что у scipy). EMA весов.
* **Инференс**: включать ли самоансамбль ×8 и с каким коэффициентом поправки — выбирается по точной
  numpy-метрике из `baseline.ipynb` на отложенных сценах валидации.

## Наблюдения о данных

* Вход — не обычный бикубик/box от эталона: размытие с широким ядром плюс шум
  (остаток линейной модели ≈ 4.7 уровня яркости), поэтому сеть учится и разблюривать, и шумодавить.
* Сдвига между входом и эталоном нет: бикубик лучше всего совпадает с эталоном без смещения.
* Маленькая версия модели (0.2 M параметров, CPU, 4k шагов L1 + 1k шагов метрики на 600 сценах):
  Score 54.4 на 40 сценах val (бикубик = 50). Фаза «метрика» дала +1.4 за 1000 шагов,
  самоансамбль ×8 снижал балл (≈ −0.5): усреднение сглаживает текстуру, которую метрика сравнивает.

## Переменные окружения (для запуска вне Colab)

| переменная | смысл |
|---|---|
| `SR_DATA` | папка с `train/ val/ test/` |
| `SR_OUT` | куда писать чекпойнты и посылку |
| `SR_PRESET` | `full` (GPU, по умолчанию), `cpu`, `smoke` |
| `SR_TRAIN_ON_VAL=1` | добавить в обучение валидацию (кроме отложенных для оценки сцен) |
| `SR_STEPS_L1`, `SR_STEPS_METRIC` | число шагов в фазах |
